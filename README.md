# 词语小侦探 · 近义词反义词训练器

按《近义词反义词软件-策划与提示词》v1.0 实施完成的单文件网页应用。

## 使用方法

**双击 `index.html` 即可使用**（Chrome / Edge / Safari 均可，手机、电脑都行）。
零依赖、零联网、零安装：所有功能离线可用，学习数据只保存在本机浏览器的 localStorage 里。

## 功能总览（对应策划案功能编号）

| 视图 | 功能 |
|---|---|
| 🔎 查词 | 汉字 / 拼音全拼 / 拼音首字母三种输入（F01），输入即搜+高亮（防抖 150ms），词条详情卡（F02），近反义词可点击跳转+返回面包屑（F03），今日一词、最近查过、收藏星标（F11） |
| ⚖️ 辨析 | 五维对比表（语义轻重/范围/色彩/搭配/词性，只显示有差异的行）（F04）、同场景例句对比（F05）、感情色彩色标（F06）、26 组高频易混精修对比、交换 A/B |
| 🎯 闯关 | 四种题型：选近义/选反义/找异类/句中替换（F07/F14）＋ 三种答题方式：**选项作答**（四选一点击）、**填写作答**（手输近/反义词，系统双向智能判分，支持"看答案"）、**自动看答案**（逐词自动展示答案，可暂停/翻页，适合背诵，不计分）；每关题量可设置（3/5/10/15/20 题，星级按正确率结算）（F08）、即时反馈+解释（F09）、难度分级（F17）、错题特训、查词详情卡"✍️ 考考我"（当场填该词的近/反义词） |
| 📚 词库 | A-Z 分组浏览+侧边字母导航（F21）、词性/年级/主题筛选（F22），内置 **5007 条词条**（以两字词为主，含情绪/品质/动作/神态/自然/动植物/食物/用品/场所/人物/学习等大类与 500+ 成语） |
| 🏠 我的 | 生词本+闪卡复习（F11）、错题本（按词聚合，连对 2 次出库，F10）、学习统计+30 天打卡日历（F23）、薄弱词 Top5、家长周报（F24）、成就徽章（F19）、词卡打印 A4 一页 8 张（F25）、数据导出/导入 JSON（F13）、音效/深色模式设置（F29） |

## 出题引擎（本产品的技术核心）

题目由「词库 × 题型模板」实时生成，干扰项执行 R1–R8 硬性规则
（正确答案唯一、杜绝双正确答案、干扰项优先取反义词/近义词、同词性、
字数差 ≤2、关内不重词、生成后全量校验）。自检入口：浏览器控制台运行
`selfTestQuiz(100)`，返回生成/失败统计，失败题用 `console.warn` 打印。

**填写判分规则**：填的词在题干的近/反义词表里 → 对；填的词的近/反义表
里有题干词（反向互认）→ 也算对；填了题干本身 → 提示换词不判分；
实在想不出来可点「看答案」（记入错题本，之后接着练）。

## 目录结构

```
词语小侦探/
├── index.html     ← 最终交付物（单文件，双击即用）
├── build.js       ← 构建脚本：把 src/ 分片组装成 index.html（node build.js）
├── src/           ← 源码分片（改词库/界面后需重新构建）
│   ├── 01-head.html      样式（设计变量/动效/打印/深色主题）
│   ├── 02-body.html      页面骨架
│   ├── 03-worddb-a.js    词库工厂 + 情绪/品质词条
│   ├── 04-worddb-b.js    动作/景物/程度/成语词条
│   ├── 04c-worddb-extra1.js  扩容：情绪/品质/动作
│   ├── 04d-worddb-extra2.js  扩容：景物/程度/成语/名词
│   ├── 05-worddb-c.js    辨析配对库 + 标签表
│   ├── 06-core.js        检索 API / 存储 / 出题引擎（纯逻辑，可单测）
│   ├── 07-ui-a.js        路由 / 查词 / 辨析视图
│   ├── 08-ui-b.js        闯关 / 词库 / 我的 / 打印 / 导入导出
│   └── 09-tail.html      收尾标签
└── test/
    ├── run.js        自动化测试入口：node test/run.js
    └── test-body.js  词条结构校验 + 近反义矛盾检测 + 出题全量自检
```

## 修改词库后如何重新发布

```bash
node test/run.js   # 先跑自检（词库校验 + 出题引擎校验）
node build.js      # 重新生成 index.html
```

## 扩词库

词库目前 **5007 条**。两种扩词方式：
1. 手工精修词条：在 `src/03-worddb-a.js` 等手工文件里写一行 `W(...)`（带 diff/例句的深度词条）。
2. 批量词条：在 `src/bulk/bulk-*.txt` 里加一行
   `词|词性|释义|近1/近2|反1|标签`（年级/色彩/标签可省略，拼音由 pinyin-pro 构建期自动标注），
   然后 `node tools/gen-db.js && node test/run.js && node build.js`。
